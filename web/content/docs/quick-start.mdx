---
title: Quick start
description: Create an agent, give it something to do, and follow along.
---

## 1. Run axel

```bash
axel
```

The first time, Axel walks you through setup: it checks your machine, then creates your
first agent. Name it (say `terra`), pick its harness, a few skills, a colour and a mode.
That generates its key, stores it in your keychain, and signs an attestation that you own
it. Later agents: `axel setup` again, or `axel agent new`.

## 2. The launcher

Setup ends in the launcher. From then on, run `axel` in any Rex terminal (or press your
[key binding](/docs/installation#a-key-binding)). Two panes float over the window:

```text
╭ why not today? ────────────────────────────────────────────────────╮
│ › What are we building?                           terra · api       │
├ threads ───────────────────────────────────────────────────────────┤
│ › type to filter                                    4 open · 2 settled │
│ ○ Rate-limit the public API   terra        api       3   41k   2h ago │
│ ● Migrate billing to Stripe   opus vega     billing   5  120k  12m ago │
╰────────────────────────────────────────────────────────────────────╯
```

The window takes the project's name. Run `axel` again to close both panes.

## 3. Type, press Enter

```text
› add retries to the webhook sender @terra
```

Enter launches straight away with what the right of the prompt shows: the agent you used
last (or the one an `@name` picks) working **in place** in the current directory. A name
you put first is dropped from the prompt (`@terra add retries…` sends "add retries…").

Want something else? Press **Tab** for the full form: which projects (several, or none for
a scratch thread), which agent, and whether to work in place or in a new git worktree.

## 4. Follow the thread

The prompt pane becomes the **thread view**: the conversation above, a composer below.

- Write to steer the agent. While it's mid-turn, your message goes into its turn, and it reads
  it at its next step. Until then you can still edit it (**Option+↑**). **Ctrl+S** interrupts
  the agent instead.
- Tool calls fold into one line; **Space** expands them, a click opens them in a pane.
- Under a turn that changed files, `Δ 3 files  +42 −7`: click it to read the diff, leave
  notes the agent gets as a review, or undo the turn.
- Questions and permission requests appear inline. Answer with **Enter**, or **1–9** to pick.
- Mention another agent, `@opus can you review this?`, to bring it onto the thread.
- The pane beside the composer shows what each agent is spending, as it spends it.

## 5. Come back later

Run `axel` and press **↓** to move into the recent threads. Type to filter, **Enter** to
reopen one. When a thread is finished, **Ctrl+S** settles it: it stays listed, dimmed, under
the open ones. **Ctrl+X** archives it and **Ctrl+D** (twice) deletes it.

From the command line:

```bash
axel thread ls                     # open threads
axel thread resume <id>            # a new session that continues the last conversation
axel thread done <id>              # settle it
```
