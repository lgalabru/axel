## Launcher

| Key | |
|---|---|
| **Enter** | Launch with the defaults shown at the right: the last agent used (or the one an `@name` names), in place, here. |
| `@name` | Pick the agent. Its name takes the agent's colour as you type. |
| **Tab** | The full form: projects, agent, workspace. The pane grows to fit. |
| **↓** | Move to the recent threads. |
| **Esc** | Close Axel. |
| Drop files | Attach them to the first prompt. **Backspace** on an empty prompt removes the last one. |

## Recent threads

| Key | |
|---|---|
| Type | Filter by title, project or agent. |
| **↑ ↓** | Move. **↑** on the first row goes back to the prompt. |
| **Enter** | Open the thread where you typed `axel`. |
| **Ctrl+S** | Settle the thread, or reopen a settled one. |
| **Ctrl+X** | Archive it: stop its sessions and hide it. |
| **Ctrl+D**, twice | Delete it. |
| **Esc** | Clear the filter, then close. |

## Thread view

| Key | |
|---|---|
| **Enter** | Send. While the agent is mid-turn, the message goes into its turn: it reads it at its next step, without stopping what it's doing. |
| **Shift+Enter** | A new line (Option+Enter works too). |
| **Ctrl+S** | Interrupt the agent and send this instead. |
| **Option+↑** | With an empty composer: edit your latest message the agent hasn't read yet. **Enter** saves it, **Esc** leaves it as it was. |
| **↑ ↓** | Move between the lines of your message; past the first or last line, prompt history. While a question is open: choose an answer. |
| **Ctrl+L** | Show the session log of the agent you're talking to, or hide it again. |
| **1–9** | Pick an answer. |
| **Tab** | Move between the composer, attachments, the messages not read yet and the timeline. There, **Enter** sends one now, **e** edits it and **x** removes it. |
| **Space** | With an empty composer: expand or fold the tool calls under the cursor. |
| **PgUp / PgDn** | Scroll the conversation. |
| `@name` | Message or summon another agent on this thread. |

### Editing your message

| Key | |
|---|---|
| **Option+← →** (or **Ctrl+← →**) | Move by word. |
| **Cmd+← →**, **Home / End**, **Ctrl+A / E** | Start or end of the line. |
| **Cmd+↑ ↓** | Start or end of the message. |
| **Option+Backspace**, **Ctrl+W** | Delete the word before the cursor. |
| **Option+Delete**, **Option+D** | Delete the word after it. |
| **Cmd+Backspace**, **Ctrl+U** | Delete to the start of the line. |
| **Ctrl+K** | Delete to the end of the line. |
| **Ctrl+Y** | Put back what you last deleted by word or line. |
| **Cmd+Z**, **Ctrl+Z** | Undo, a word at a time. **Shift+Cmd+Z** redoes. |

Pasted text keeps its line breaks.

## Dashboard

| Key | |
|---|---|
| **n** | New thread. |
| **Enter** | Open the selected thread. |
| **o** | Focus the agent's own pane. |
| **s** | Spawn another agent onto the selected thread. |
| **Tab** | Next widget: threads, agents, tokens, inbox. |
| **i** | Inbox. |
| **q** | Quit. |
