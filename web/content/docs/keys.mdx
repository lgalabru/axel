## Launcher

| Key | |
|---|---|
| **Enter** | Launch with the defaults shown at the right: the last agent used (or the one an `@name` names), in place, here. |
| `@name` | Pick the agent. Its name takes the agent's colour as you type. |
| **Tab** | The full form: projects, agent, workspace. The pane grows to fit. |
| **↓** | Move to the recent threads. |
| **Esc** | Close Axel. |
| Drop files | Attach them to the first prompt. **Backspace** on an empty prompt removes the last one. |

## Recent threads

| Key | |
|---|---|
| Type | Filter by title, project or agent. |
| **↑ ↓** | Move. **↑** on the first row goes back to the prompt. |
| **Enter** | Open the thread where you typed `axel`. |
| **Ctrl+S** | Settle the thread, or reopen a settled one. |
| **Ctrl+X** | Archive it: stop its sessions and hide it. |
| **Ctrl+D**, twice | Delete it. |
| **Esc** | Clear the filter, then close. |

## Thread view

| Key | |
|---|---|
| **Enter** | Send. While the agent is mid-turn, the message goes into its turn: it reads it at its next step, without stopping what it's doing. |
| **Shift+Enter** | A new line (Option+Enter works too). |
| **Ctrl+S** | Interrupt the agent and send this instead. |
| **Option+↑** | With an empty composer: edit your latest message the agent hasn't read yet. **Enter** saves it, **Esc** leaves it as it was. |
| **↑ ↓** | Move between the lines of your message; past the first or last line, prompt history. While a question is open: choose an answer. |
| **Ctrl+L** | Show the session log of the agent you're talking to, or hide it again. |
| **Ctrl+T** | Open a floating terminal in the thread’s project directory or worktree. |
| **Ctrl+D** | The thread controls: its sessions and spend, and reset, move, settle, archive, stop, rename. |
| **1–9** | Pick an answer. |
| **Tab** | Move between the composer, attachments, the messages not read yet and the timeline. There, **Enter** sends one now, **e** edits it and **x** removes it. |
| **Space** | With an empty composer: expand or fold the tool calls under the cursor. |
| **PgUp / PgDn** | Scroll the conversation. |
| `@name` | Message or summon another agent on this thread. |
| Click `▸ 5 tool calls` | Open the run of calls in a pane. |
| Click `Δ 3 files  +42 −7` | Open the turn's diff pane. |
| Click a 📎 chip | Show the attached file in Finder. |

### Editing your message

| Key | |
|---|---|
| **Option+← →** (or **Ctrl+← →**) | Move by word. |
| **Cmd+← →**, **Home / End**, **Ctrl+A / E** | Start or end of the line. |
| **Cmd+↑ ↓** | Start or end of the message. |
| **Option+Backspace**, **Ctrl+W** | Delete the word before the cursor. |
| **Option+Delete**, **Option+D** | Delete the word after it. |
| **Cmd+Backspace**, **Ctrl+U** | Delete to the start of the line. |
| **Ctrl+K** | Delete to the end of the line. |
| **Ctrl+Y** | Put back what you last deleted by word or line. |
| **Cmd+Z**, **Ctrl+Z** | Undo, a word at a time. **Shift+Cmd+Z** redoes. |

Pasted text keeps its line breaks.

## Thread controls

Opened with **Ctrl+D** from the composer, or `axel thread manage <id>`. On top, the
thread's sessions: agent, harness and model, state, turns, tool calls, tokens, cost,
context fill and how long each ran, then the thread's totals and the last hour. Below,
what you can do to it.

| Key | |
|---|---|
| **↑ ↓**, **Enter** | Choose. Each row has a key too: **r** reset, **m** move, **s** settle, **o** reopen, **a** archive, **x** stop, **n** rename, **h** hard reset. |
| **Reset** | End the thread's sessions, start the agent again with a fresh context and a recap of the thread (the intent, the last turns in a few lines each, the files they changed), and relaunch the thread's own panes. Everything comes back on the installed binary. For when a long thread has grown slow, or after an update. |
| **Move** | Run the agent on one of your hosts. A live Claude Code session travels with its conversation; anything else starts there with the recap. |
| **Settle** / **Reopen**, **Archive**, **Stop** | As in the launcher. |
| **Rename** | Edit the title in place; the window follows. |
| **Hard reset** (in red, last) | End every session and relaunch the panes, starting nobody and carrying nothing over: the next message on the thread starts a brand-new conversation. |
| **y / n** | Confirm or back out. **Esc** closes. |

## Diff pane

Opened from a turn's change line, or with `axel thread diff <id> --pane`.

| Key | |
|---|---|
| **↑ ↓** | Pick a file. The agent's own files come first, the rest under *also changed during this turn*. |
| **j / k** | Move through the diff, by line, or by row when side by side. **PgUp / PgDn** page; **g / G** jump to the ends. |
| **s** | Switch between side by side (old left, new right) and one column. Panes 110 columns or wider start side by side. |
| **v** | Start or clear a mark; move with **j** to extend it. |
| **c** | Write a note under the marked lines (or the cursor line). **Enter** saves it, **Esc** drops it. |
| **d** | Remove the note under the cursor. |
| **Enter** | Send every note to the agent as one review, each with its path, line range and the marked lines. |
| **u**, then **y** | Undo the turn in the working tree, keeping later work unless it overlaps. Not offered while the agent is mid-turn. |
| **R** | After an undo that hit overlapping work: restore the turn's files to how they were before it. |
| **[ ]** | The previous or next turn of the same agent. |
| **q**, **Esc** | Close. Notes you haven't sent are kept. |

| Key | |
|---|---|
| **n** | New thread. |
| **Enter** | Open the selected thread. |

| **s** | Spawn another agent onto the selected thread. |

| **i** | Inbox. |
